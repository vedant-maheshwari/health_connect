Overview

HealthConnect is a microservices-based telehealth platform with 12 independent services communicating via RESTful APIs and WebSockets.

Authentication Guide

JWT Token-Based Authentication

Most endpoints require a JWT (JSON Web Token) for authentication. Here's how to use it:

1. Login to Get Token

curl -X POST http://localhost:8000/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=user@example.com&password=yourpassword"

Response:

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "role": "PATIENT",
  "user_id": 123
}

2. Use Token in Requests

curl -X GET http://localhost:8000/patients/me \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

User Roles

  • PATIENT - Regular patients
  • DOCTOR - Healthcare providers
  • FAMILY - Family members/caregivers
  • ADMIN - System administrators

Appointment Service

Slot management, booking, and real-time updates

:8004
GET /available-appointments?doctor_id={id}&app_date={date} Auth Required

Get available time slots for a doctor

// Response
{
  "available_slots": [
    {
      "slot_datetime": "2026-01-25T10:00:00",
      "duration_minutes": 30
    }
  ]
}
POST /reserve_slot Auth Required

Reserve a slot temporarily (5 minutes hold)

// Request Body
{
  "doctor_id": 1,
  "slot_datetime": "2026-01-25T10:00:00",
  "severity": 1
}

// Response
{
  "message": "Slot reserved for 5 minutes",
  "expires_at": "2026-01-25T10:05:00"
}
POST /confirm_slot Auth Required

Confirm a reserved slot and create appointment

// Request Body
{
  "doctor_id": 1,
  "slot_datetime": "2026-01-25T10:00:00",
  "severity": 1,
  "triage_id": "optional_triage_case_id"
}
GET /appointments Auth Required

Get all appointments for current user

POST /appointments/cancel/{appointment_id} Auth Required

Cancel an appointment

WebSocket /ws/appointments/{doctor_id}

Real-time appointment updates for doctors

Common Workflows

1. Patient Registration & Login

sequenceDiagram participant User participant Gateway as API Gateway participant Auth as Auth Service participant DB as Database User->>Gateway: POST /register/patient Gateway->>Auth: Forward registration Auth->>DB: Create user record DB-->>Auth: User created Auth-->>Gateway: Return user data Gateway-->>User: 201 Created User->>Gateway: POST /token (login) Gateway->>Auth: Validate credentials Auth->>DB: Check user DB-->>Auth: User found Auth-->>Gateway: JWT token Gateway-->>User: Token + user info

2. Appointment Booking Flow

sequenceDiagram participant Patient participant Gateway participant Appt as Appointment Service participant Redis participant DB Patient->>Gateway: GET /available-appointments Gateway->>Appt: Forward request Appt->>DB: Query available slots DB-->>Appt: Return slots Appt-->>Patient: Available slots list Patient->>Gateway: POST /reserve_slot Gateway->>Appt: Reserve slot Appt->>Redis: Set 5-min hold (TTL) Redis-->>Appt: Slot reserved Appt-->>Patient: Reservation confirmed Patient->>Gateway: POST /confirm_slot Gateway->>Appt: Confirm reservation Appt->>Redis: Check reservation Appt->>DB: Create appointment DB-->>Appt: Appointment created Appt-->>Patient: Booking confirmed

3. Family Member Invitation

sequenceDiagram participant Patient participant Family as Family Service participant DB participant FamilyMember as Family Member Patient->>Family: POST /send_invitation Family->>DB: Create invitation DB-->>Family: Invitation created Family-->>Patient: Invitation sent FamilyMember->>Family: GET /invitations Family->>DB: Query invitations DB-->>Family: Pending invitations Family-->>FamilyMember: Show invitations FamilyMember->>Family: POST /respond_invitation Family->>DB: Update invitation status Family->>DB: Create family link DB-->>Family: Link created Family-->>FamilyMember: Access granted

Error Handling

Standard Error Response

{
  "detail": "Error message description"
}

Common HTTP Status Codes

Code Meaning Example
200 Success Request completed successfully
201 Created Resource created (e.g., new user)
400 Bad Request Invalid request parameters
401 Unauthorized Missing or invalid JWT token
403 Forbidden Insufficient permissions
404 Not Found Resource doesn't exist
409 Conflict Slot already booked
422 Validation Error Request data validation failed
500 Server Error Internal service error
