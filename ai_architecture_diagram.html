How The System Works - 6 Steps

1

Audio Input (Optional)

Patient speaks symptoms in Hindi/Hinglish

Sarvam AI converts speech to text and translates

Multilingual Support
2

Patient Describes Symptoms

Text description or image sent to API Gateway

Request routed to Orchestrator for processing

Supports Text & Images
3

Search Similar Past Cases

Cohere creates semantic embeddings of symptoms

GPT-4o-mini filters and ranks relevant matches

RAG: Retrieval-Augmented Generation
4

AI Diagnosis

Dr. AIDEN (GPT-4o) analyzes:

• Current patient symptoms
• Relevant past cases
• Medical knowledge base

Context-Aware Medical Triage
5

Return Assessment

Patient receives complete assessment:

• Recommended specialist
• Severity level (1-5)
• Clinical notes and reasoning

Saved to Database
6

Doctor Correction & Learning

Doctor reviews and corrects AI assessment

AI analyzes the mistake, creates lesson, stores for future use

Continuous Improvement Loop

The 4 AI Agents

1. Sarvam AI

  • Transcribes Hindi/Hinglish audio to text
  • Translates to English for processing
  • Models: Saarika v2.5 (STT) + Saaras v2.5 (Translation)
  • Optimized for Indian languages

2. Cohere

  • Creates semantic vector embeddings
  • Understands meaning across languages
  • Model: embed-multilingual-v3.0
  • Powers the RAG search system

3. GPT-4o-mini

  • Fast and cost-effective assistant
  • Filters search results for relevance
  • Translates text when needed
  • Semantic relevance checking

4. GPT-4o (Dr. AIDEN)

  • Main medical triage engine
  • Makes specialist recommendations
  • Assigns severity levels
  • Learns from doctor corrections
